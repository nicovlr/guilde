# ADR-0002 : Pas de LICENSE tant que Nico n'a pas décidé

- Status: accepted
- Date: 2026-09-30

## Contexte

Licence et publication open source sont des décisions réservées à Nico.

## Décision

Aucun fichier `LICENSE` dans le dépôt jusqu'à arbitrage explicite (issue `question`).

## Conséquences

Le code reste privé ; pas d'ambiguïté de licence publique.
